# Projeto Roblox 🎣

Este projeto é para estudar programação e automação de tarefas repetitivas no Windows.

## Objetivos

* Aprender Python.
* Praticar automação de teclado e mouse em uma janela de teste.
* Estudar como funcionam minigames de pesca.

## Segurança

Os testes serão realizados em ambientes próprios, respeitando as regras dos jogos.
